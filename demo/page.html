Embedded document

This page is inside an <iframe> with sandbox="allow-scripts allow-forms allow-popups".

allow-same-origin is deliberately absent, so this document has an opaque origin and cannot reach the demo's cookies or storage. The chrome above still works, because it only ever touches this frame’s element attributes.

Load states are tracked by the binding, and a load event means navigation completed — not that it succeeded. A 404 and a good page both fire it, which is why the error state is not derived from it.
